# Harajat bot

Kunlik xarajatlar va har kungi eslatmalar uchun Telegram bot.

## Railway'ga joylash

1. Railway'da **New Project → Deploy from GitHub repo** ni tanlang va shu repositoryni ulang.
2. **Variables** bo'limiga `BOT_TOKEN` ni yozing (@BotFather'dan olingan token).
3. Xizmatga **Volume** qo'shing va uni `/data` ga ulang. Volume bo'lmasa, xarajatlar va eslatmalar har deploy'da o'chadi.
